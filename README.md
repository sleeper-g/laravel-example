### Миграции в Laravel

Миграции — это способ управления структурой базы данных через код. Они позволяют создавать, изменять и откатывать таблицы и их столбцы, обеспечивая синхронность базы данных между разными средами. Миграции облегчают командную работу, обеспечивая единообразие базы данных.

**Пример**:

```php
php artisan migrate  // Применяет миграции
php artisan migrate:rollback  // Откатывает миграции
```

### Eloquent ORM в Laravel

Eloquent ORM (Object-Relational Mapping) — это система для работы с базой данных через модели. Она позволяет выполнять операции с данными (создание, чтение, обновление, удаление) с помощью объектно-ориентированного подхода, скрывая сложность SQL-запросов.

**Пример**:

```php
$group = Group::find(1);  // Находит группу по ID
$students = $group->students;  // Получает всех студентов группы
```

Eloquent также поддерживает реляционные связи, такие как "один ко многим" и "многие ко многим".
